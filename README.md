# Ejercicios de Lógica y Estructuras de Control en Python 🐍

Colección de ejercicios prácticos desarrollados en Python enfocados en el uso de condicionales (`if`, `elif`, `else`), operadores lógicos, validación de datos y manejo de listas.

## 📋 Ejercicios Incluidos

### 1. Validación de Usuarios 👤
Sistema simple que verifica si un nombre ingresado se encuentra registrado en una lista predefinida.

### 2. Calculadora de Año Bisiesto 📅
Determina si un año ingresado por el usuario es bisiesto aplicando reglas aritméticas y operadores de módulo (`%`).

### 3. Simulador de Cajero Automático 🏦
Simula la operación de un cajero con las siguientes reglas:
- Validaciones de longitud para número de cuenta (10 dígitos) y PIN (4 dígitos).
- Verificación de fondos y procesamiento de retiros.
- Clasificación del estado de la cuenta (*Saludable*, *Estable*, *Saldo bajo*, *En cero*) según el saldo restante.

### 4. Control de Tráfico y Tiempos de Semáforo 🚦
Calcula los tiempos de espera del semáforo considerando:
- Hora del día y día de la semana (hora pico vs. tráfico normal vs. fin de semana).
- Impacto de condiciones climáticas (lluvia).
- Alertas de precaución para peatones según la duración del tiempo en verde.

## 🛠️ Tecnologías
- **Lenguaje:** Python 3.x
- **Entorno:** Consola / Terminal
